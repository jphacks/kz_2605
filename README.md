## 製品概要
### 背景(製品開発のきっかけ、課題等）
AIから答えを得やすい時代だからこそ、答えを受け取るだけでなく、自分で判断し、その理由を考える体験を大切にしたいと考えました。価値観や立場によって判断が変わる「正解のない問い」には、自分の選択を確かめ、他者の考えに触れる機会が必要です。

その入り口として着目したのが、親しみのある昔話です。「もし浦島太郎が亀を助けなかったら？」「開けてはいけないと言われた玉手箱を、どうする？」。物語を聞いて考えるだけでなく、当事者として行動し、違う結末を体験できれば、自分の判断を振り返るきっかけになると考えました。

また、VRは没入感がある一方で、ヘッドセットをかぶった1人だけの体験になりがちです。そこで配信・投票・コメントを組み合わせ、周りの人も選択に参加できる形にしました。同じ場面でも、自分と違う判断をする人がいる。その違いを知り、「なぜそう選んだのか」を話し合う体験を目指しています。

### 製品説明（具体的な製品の説明）
「童話配信」は、絵本の中に入り込んで浦島太郎を演じる Meta Quest 向けのVRコンテンツです。体験の様子はスマホにそのまま配信され、視聴者も物語の分岐に参加できます。

**もし、自分が浦島太郎だったら？** 自分の行動で結末を変える楽しさを通じて、正解のない問いを考え、他者と判断を比べるきっかけをつくる作品です。

部屋で絵本を開くと、光に包まれて物語の世界へ吸い込まれます。浜辺、海の中、竜宮城、故郷の村と進みながら、5つの分岐点で浦島太郎の行動を自分の体で選びます。ボタンを押して選ぶのではありません。子どもたちを手で追い払う、首を横に振って断る、料理を手に取って口に運ぶ、玉手箱のふたを持ち上げる。現実と同じしぐさがそのまま選択になります。選び方しだいで、物語は9つの結末に分かれます。

周りの人は、タイトル画面に出るURLをスマホで開くだけで、体験者のVR視点の映像、ナレーションの字幕、いまの選択肢をリアルタイムに見られます。コメントは弾幕としてVR空間にも流れます。選択肢には投票でき、体験者が迷って時間切れになると、視聴者の投票1位で物語が進みます。

### 特長
#### 1. 体の動きがそのまま物語の選択になる
選択肢は、物語の中で浦島太郎が実際にとる行動として用意しています。木の棒で亀を叩く、乙姫の手を取る、宴会場の奥の通路へ進むなど、手・頭・移動で選びます。VRならではの「自分が物語を動かしている」感覚を大事にしました。

#### 2. 誰もが知る昔話から、誰も知らない9つの結末へ
亀を見過ごすと「始まらない物語」（コメディ）。一緒にいたずらすると「亀の逆襲」（ホラー）。竜宮城の禁じられた部屋に入る、玉手箱をおじさんに託すなど、よく知った話が少しずつ別の物語へ変わっていきます。到達したエンディングは記録され、全部の結末を集める楽しみもあります。

#### 3. 見ている人も物語に参加できる
アプリのインストールやログインは不要です。スマホのブラウザでURLを開くだけで、VR視点の映像・字幕・選択肢を見ながら、投票・コメント・リアクションを送れます。体験者が迷っている間に視聴者が背中を押す、という1人用VRにはなかった遊び方ができます。

#### 4. 違う選択と、その理由を話し合うきっかけになる
配信を加えたのは、観戦できるようにするためだけではありません。VRの中で行動する体験者と、外から見て投票する視聴者が、同じ場面を異なる立場で捉える体験を目指しました。コメントで選んだ理由を伝えたり、結末を見て「別の選択ならどうなったか」を話し合ったりできます。投票1位は物語を進めるための仕組みであり、道徳的な正解を示すものではありません。「多数派の選択なら正しいのか」も、振り返りの問いになります。

### 解決出来ること
* 昔話を受け取るだけでなく、自分で選び、結果を見て判断を振り返る機会をつくれます。
* VR体験中に周りの人が待っている時間を、投票・コメントで一緒に物語を動かす時間に変えられます。
* 体験者と視聴者が異なる判断や理由を共有し、正解のない問いについて話し合うきっかけをつくれます。
* ボタン操作に慣れていない子どもや大人でも、普段の仕草だけで遊べます。

### 想定ユーザー・活用構想
主な活用先として、小学校の道徳・国語の授業を想定しています。1台のMeta Questで代表者が体験し、周りの児童はスマホやタブレットから投票・コメントで参加する構成です。全員分のVR機器を用意せずに、同じ選択と結末を共有する授業を目指します。科学館・図書館の体験展示や、親子での利用も想定しています。

授業では、選ぶ前に理由を考え、体験後に「自分はなぜ選んだか」「別の立場ならどう考えるか」を話し合う流れを構想しています。VRの分岐・配信・投票・コメントは実装済みですが、授業用教材の整備や教育効果の検証は今後の課題です。

### 今後の展望
* 桃太郎、かぐや姫、赤ずきんなど、ほかの昔話・童話の絵本を増やす。
* 視聴者の投票で、物語の途中の出来事（天気、登場人物のセリフなど）も変えられるようにする。
* 学校や図書館で、1人のVR体験に周りの人が投票で参加する使い方を検証し、体験前後の対話につながる教材を整備する。
* ナレーションと字幕の多言語化。

### 注力したこと（こだわり等）
* **絵本に入り、絵本から戻る演出**：絵本が光って吸い込まれる始まり方と、物語が光にほどけて部屋の絵本へ戻る終わり方を、対になるように作りました。暗転・白転は場面転換の酔い対策も兼ねています。
* **選択を体の動きで判定する仕組み**：叩く（手や棒の速さ）、首を振る（往復の回数）、口へ運ぶ、立ち去る、ふたを開けるなど、行動ごとに検出器を作りました。どの選択肢も物語の中の自然な行動になるよう設計しています。
* **回線が遅くても遅れが溜まらない配信**：送る内容を1本のリクエストにまとめ、受信はストリーミングで受けます。VR視点の画像は低解像度で撮り、JPEGへの変換を別スレッドで行うので、Questの描画が引っかかりません。
* **酔いにくい配信カメラ**：体験者の頭を少し遅れて追いかけ、傾きや細かな揺れを抑えたカメラで、視聴者も見やすい映像にしました。
* **全ルートの自動テスト**：9つのエンディングすべてに到達できることを、PlayModeテストで確認しています。
* **自作のモデリング**：AIを活用したものや、1度も手を借りなかったものまで、私たちの想像した浦島太郎を自らの手で形にしました。
